# Key prompts

`keyboard/` holds keyboard and mouse prompt images from Xelu's Free Controller & Key Prompts by Nicolae "Xelu" Berbece (Those Awesome Guys), https://thoseawesomeguys.com/prompts/. The pack's readme places every asset in the public domain under Creative Commons 0 (CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/). Credit is welcome but not required.

Only the images the key map and the numpad debug menu use are copied here (the menu also draws Num Lock and the tall + and Enter), from the pack's `Keyboard & Mouse/Light` set (light keys read on the dark Station screens), plus `Blanks/Blank_White_Normal.png`, which `KeyPrompt` draws under a glyph for any key with no picture of its own. Files keep the pack's names: `<Name>_Key_Light.png`.
